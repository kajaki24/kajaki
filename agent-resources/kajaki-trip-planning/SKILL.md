# Plan a Kajaki24 trip

Read the current public pages before quoting prices or route details:

- [Prices](https://kajaki24.com.pl/cennik/)
- [Routes](https://kajaki24.com.pl/trasy/)
- [Contact and booking enquiries](https://kajaki24.com.pl/kontakt/)

These pages also accept `Accept: text/markdown`. The homepage summary is
available at https://kajaki24.com.pl/llms.txt.

Compare routes using the user's starting point, time available, group size and
experience. Preserve distinctions between per-person, per-kayak and group prices
as published. If a price or condition is missing, say it needs confirmation.
Link the source page for the selected route and price.

Published prices do not establish availability for a date. Direct booking
enquiries to the contact methods listed on the site. This website offers no
public booking API, agent registration, MCP server or A2A agent. Do not report
a reservation as made based on reading the website or preparing an enquiry.

In browsers with WebMCP support, `kajaki_read_information` retrieves published
information for `prices`, `routes` or `contact`. It is read-only and does not
send messages, reserve equipment or take payments.
